# APKLIS — Novedades de la versión 1.2.0

Textos para la ficha de la tienda. Solo cambios visibles para quien usa la app.
Sin detalles técnicos ni credenciales.

## Campo «Novedades» (texto corto, listo para pegar)

```
Novedades de la versión 1.2.0

• La tasa informal ya aparece sin configurar nada.
• Nuevas monedas: dólar canadiense (CAD), Clásica (CLA) y dólar por Zelle.
• Cada tasa se calcula con el mismo criterio que la web de elToque.
```

## Descripción larga (opcional, para la ficha ampliada)

**Tasa informal más fácil y más fiel**

La pestaña elToque ya no necesita ningún ajuste previo: al abrirla aparece la
tasa del mercado informal tal como se consulta hoy en día.

Se suman tres referencias que antes no estaban: el dólar canadiense (CAD), la
Clásica (CLA) y el dólar pagado por Zelle. Cada una aparece con su propia
tarjeta, junto a USD, MLC, EUR y las demás monedas habituales.

Además, cada tasa se calcula con el mismo criterio que usa la web de elToque,
sin promedios propios: cuando una moneda tiene muchas operaciones se toma el
valor más representativo del día y, cuando tiene pocas, se pondera igual que
en la web. Así la app no aplica una regla distinta a cada moneda.

**Publicado o en vivo, tú eliges**

La nueva vista «Tiempo real» permite alternar entre:

- **Publicada**: el valor de referencia del día, en la ventana de 7:00 a 7:00.
- **Tiempo real**: el valor vivo, el mismo que muestra la web de elToque, que
  cambia a medida que entran operaciones.

Si prefieres una cifra estable para comparar o convertir, usa la publicada. Si
quieres saber cómo está el mercado en este momento, usa la de tiempo real.

**Más liviana**

La instalación bajó de unos 110 MB a unos 47 MB, sin perder funciones.

**Estabilidad**

Se corrigieron fallos que podían dejar la tasa informal sin cargar en algunas
instalaciones.
